Installa dal Chrome Web Store

Protezione tramite password per Chrome

Scudo Browser è un'estensione per Google Chrome progettata per richiedere una password all'avvio di una nuova sessione del browser. Dopo lo sblocco puoi continuare a utilizzare schede e finestre durante la stessa sessione senza reinserire continuamente la password.

La configurazione della password viene memorizzata localmente nel browser e non è necessario creare un account.

Funzioni principali

🔐 Protezione con password

Richiede la password configurata quando inizia una nuova sessione protetta.

🔒 Blocco manuale

Puoi bloccare nuovamente la sessione quando desideri tramite la funzione dedicata.

💻 Configurazione locale

Le impostazioni della protezione vengono conservate localmente.

🆓 Gratuito

Scudo Browser è gratuito. Non è necessario alcun abbonamento.

Quando può essere utile?

Scudo Browser può essere utile su computer condivisi, PC familiari o postazioni nelle quali si desidera aggiungere una barriera di accesso alla sessione Chrome.

Scudo Browser è un'estensione di Chrome e non sostituisce la protezione dell'account Windows, macOS o del sistema operativo.
