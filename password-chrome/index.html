Come mettere una password a Chrome

Google Chrome non dispone di una password integrata dedicata all'apertura della sessione del browser. Scudo Browser permette di aggiungere una protezione tramite password locale.

Proteggere l'accesso a Chrome

Scudo Browser è un'estensione per Google Chrome che aggiunge una richiesta di password all'accesso alla sessione protetta del browser. La password viene configurata direttamente dall'utente.

Quando Chrome viene chiuso completamente e successivamente riaperto, Scudo Browser richiede nuovamente la password prima di consentire l'accesso alla sessione protetta.

Come funziona

1

Installa Scudo Browser

Installa gratuitamente l'estensione dal Chrome Web Store.

2

Configura la password

Imposta la password nelle impostazioni dell'estensione.

3

Proteggi la sessione

Alla nuova sessione protetta inserisci la password per accedere a Chrome.

Una sola password per la sessione

Dopo aver sbloccato correttamente la sessione, puoi continuare a utilizzare normalmente Chrome e aprire nuove schede e finestre senza reinserire continuamente la password.

Se vuoi proteggere immediatamente la sessione senza chiudere Chrome, puoi utilizzare la funzione “Blocca adesso”.

Domande frequenti

Chrome ha una password integrata?

No. Chrome non offre una password separata specificamente destinata a bloccare l'apertura della sessione del browser. Scudo Browser aggiunge questa protezione tramite un'estensione.

La password viene richiesta per ogni nuova scheda?

No. Dopo aver sbloccato la sessione puoi aprire normalmente nuove schede e finestre senza reinserire continuamente la password.

Quando può essere utile?

Può essere utile su computer condivisi, PC familiari o postazioni nelle quali vuoi aggiungere una barriera di accesso alla sessione Chrome.

Scudo Browser protegge tutto il computer?

No. Scudo Browser protegge l'accesso alla sessione Chrome attraverso l'estensione e non sostituisce le protezioni del sistema operativo.

Scudo Browser è gratuito?

Sì. Scudo Browser è gratuito. Il progetto può essere sostenuto facoltativamente tramite una donazione, senza sbloccare funzionalità aggiuntive.

Serve creare un account?

No. Scudo Browser funziona senza registrazione.
