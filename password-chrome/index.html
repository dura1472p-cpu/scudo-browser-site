Come mettere una password a Chrome

Google Chrome non dispone di una funzione integrata che permetta di impostare una password dedicata per proteggere l'apertura della sessione del browser.

Con Scudo Browser puoi aggiungere una richiesta di password alla sessione di Chrome, creando un ulteriore livello di protezione quando altre persone possono utilizzare il tuo computer.

È possibile mettere una password a Google Chrome?

Chrome permette di proteggere diversi dati attraverso l'account Google e le funzioni del sistema operativo, ma non offre una password separata da inserire ogni volta che si avvia una nuova sessione del browser.

Scudo Browser è un'estensione gratuita progettata proprio per aggiungere questa funzione alla sessione Chrome.

Come impostare la password

  1. Installa Scudo Browser dal Chrome Web Store.
  2. Apri le impostazioni dell'estensione.
  3. Configura la password che desideri utilizzare.
  4. Chiudi completamente Chrome.
  5. Riapri Chrome e inserisci la password per accedere alla sessione.

Cosa succede dopo aver inserito la password?

Dopo lo sblocco puoi continuare a utilizzare normalmente Chrome. Durante la stessa sessione puoi aprire nuove schede e finestre senza dover reinserire continuamente la password.

Quando Chrome viene chiuso completamente e viene avviata una nuova sessione, la protezione torna attiva e viene nuovamente richiesta la password.

Posso bloccare Chrome senza chiuderlo?

Sì. Scudo Browser dispone della funzione “Blocca adesso”, che permette di attivare immediatamente la schermata di protezione senza dover prima chiudere Chrome.

Quando può essere utile una password per Chrome?

Può essere utile quando utilizzi un computer condiviso, un PC familiare o una postazione alla quale possono accedere altre persone e vuoi aggiungere una protezione all'accesso alla tua sessione del browser.

La password protegge tutto il computer?

No. Scudo Browser protegge l'accesso alla sessione Chrome attraverso l'estensione. Non sostituisce la password di Windows, le funzioni di sicurezza del sistema operativo o la protezione dell'account Google.

Scudo Browser è gratuito?

Sì. Scudo Browser è gratuito. È possibile sostenere facoltativamente il progetto con una donazione, ma le donazioni non sbloccano funzionalità aggiuntive.

Installa Scudo Browser

Puoi installare Scudo Browser gratuitamente dal Chrome Web Store e configurare la tua password.
