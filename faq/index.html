FAQ Scudo Browser

Qui trovi le risposte alle domande più comuni su Scudo Browser, sulla protezione tramite password e sul funzionamento dell'estensione con Google Chrome.

Che cos'è Scudo Browser?

Scudo Browser è un'estensione per Google Chrome che permette di proteggere l'accesso alla sessione del browser tramite una password configurata dall'utente.

Come mettere una password a Chrome?

Google Chrome non dispone di una password integrata dedicata all'apertura della sessione del browser. Scudo Browser aggiunge questa protezione tramite un'estensione.

Per maggiori dettagli puoi leggere la guida come mettere una password a Chrome.

Come bloccare Chrome con password?

Dopo aver configurato Scudo Browser, la password viene richiesta quando viene avviata una nuova sessione protetta di Chrome. È inoltre possibile utilizzare la funzione “Blocca adesso” per attivare immediatamente la protezione.

Consulta anche la guida come bloccare Chrome con password.

Chrome ha una password integrata per aprire il browser?

No. Chrome non offre una password separata specificamente destinata a bloccare l'apertura della sessione del browser. Scudo Browser aggiunge questa funzione tramite un'estensione.

La password viene richiesta per ogni nuova scheda?

No. Dopo aver inserito correttamente la password e sbloccato la sessione, puoi aprire normalmente nuove schede e finestre senza reinserire continuamente la password.

Cosa succede quando chiudo completamente Chrome?

Quando Chrome viene chiuso completamente e successivamente riaperto, Scudo Browser torna a proteggere l'accesso alla nuova sessione e richiede nuovamente la password.

Posso bloccare Chrome senza chiuderlo?

Sì. La funzione “Blocca adesso” permette di attivare immediatamente la schermata di protezione.

La password viene inviata online?

No. La configurazione della password viene salvata localmente sul dispositivo.

Serve creare un account?

No. Scudo Browser funziona senza registrazione.

Scudo Browser protegge tutto il computer?

No. Scudo Browser protegge l'accesso alla sessione Chrome attraverso l'estensione. Non sostituisce la password di Windows o le altre funzioni di sicurezza del sistema operativo.

Scudo Browser è gratuito?

Sì. Scudo Browser è gratuito. È possibile sostenere facoltativamente il progetto con una donazione, senza sbloccare funzionalità aggiuntive.

Dove posso installare Scudo Browser?

Scudo Browser è disponibile sul Chrome Web Store.
