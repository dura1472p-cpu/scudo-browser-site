Come bloccare Chrome con password

Google Chrome non dispone di una funzione integrata per bloccare il browser con una password.

Scudo Browser aggiunge una protezione alla sessione Chrome tramite password.

Quando può essere utile

La protezione può essere utile su computer condivisi, PC familiari o postazioni dove serve maggiore privacy.

Come funziona

1. Configura la password.
2. Chiudi e riapri Chrome.
3. Inserisci la password per accedere alla sessione.
