Come bloccare Chrome con password

Google Chrome non dispone di una funzione integrata che permetta di proteggere l'apertura della propria sessione del browser con una password dedicata.

Se utilizzi un computer condiviso o vuoi impedire che altre persone accedano immediatamente alle schede e alla sessione di Chrome, puoi utilizzare Scudo Browser.

Proteggere l'accesso a Chrome

Scudo Browser è un'estensione gratuita per Google Chrome che aggiunge una richiesta di password all'accesso alla sessione del browser. La password viene configurata direttamente dall'utente.

Quando Chrome viene chiuso completamente e successivamente riaperto, Scudo Browser richiede nuovamente la password prima di consentire l'accesso alla sessione protetta.

Come funziona

  1. Installa Scudo Browser dal Chrome Web Store.
  2. Configura la password nelle impostazioni dell'estensione.
  3. Chiudi completamente Chrome.
  4. Alla successiva apertura inserisci la password per accedere alla sessione.

Durante la stessa sessione, dopo lo sblocco, puoi continuare a utilizzare normalmente Chrome e aprire nuove schede e finestre.

Bloccare Chrome immediatamente

Scudo Browser include anche la funzione “Blocca adesso”. Puoi utilizzarla quando vuoi lasciare temporaneamente il computer e desideri proteggere subito la sessione del browser.

Quando può essere utile

La protezione può essere utile su computer condivisi, PC familiari, postazioni di lavoro o in tutte le situazioni in cui desideri aggiungere un livello di privacy all'accesso alla tua sessione Chrome.

Chrome ha una password integrata?

No. Google Chrome non offre una password separata specificamente destinata a bloccare l'apertura del browser. Scudo Browser aggiunge questa protezione tramite un'estensione.

La password viene richiesta per ogni nuova scheda?

No. Dopo aver sbloccato correttamente la sessione, puoi aprire nuove schede e finestre senza reinserire continuamente la password. La protezione torna attiva quando viene avviata una nuova sessione di Chrome oppure quando utilizzi “Blocca adesso”.

Scudo Browser è gratuito?

Sì. Scudo Browser è gratuito. Il progetto può essere sostenuto facoltativamente tramite una donazione, senza sbloccare funzionalità aggiuntive.
