Come bloccare Chrome con password

Scudo Browser permette di aggiungere una protezione tramite password alla sessione di Google Chrome e di bloccarla nuovamente quando necessario.

Proteggere l'accesso a Chrome

Google Chrome non dispone di una funzione integrata specifica per bloccare l'apertura della sessione del browser con una password separata. Scudo Browser aggiunge questa protezione attraverso un'estensione.

Quando Chrome viene chiuso completamente e successivamente riaperto, Scudo Browser richiede nuovamente la password prima di consentire l'accesso alla sessione protetta.

Come funziona

1

Installa l'estensione

Installa gratuitamente Scudo Browser dal Chrome Web Store.

2

Configura la password

Imposta la password che utilizzerai per accedere alla sessione protetta.

3

Riavvia Chrome

Chiudi completamente Chrome e riaprilo per iniziare una nuova sessione.

4

Sblocca la sessione

Inserisci la password configurata per accedere alla sessione protetta.

Bloccare Chrome immediatamente

Scudo Browser include anche la funzione “Blocca adesso”, che permette di attivare immediatamente la schermata di protezione senza dover prima chiudere Chrome.

Può essere utile quando vuoi lasciare temporaneamente il computer e desideri proteggere subito l'accesso alla sessione del browser.

Domande frequenti

Chrome ha una password integrata?

No. Chrome non offre una password separata specificamente destinata a bloccare l'apertura della sessione del browser. Scudo Browser aggiunge questa protezione tramite un'estensione.

La password viene richiesta per ogni nuova scheda?

No. Dopo aver sbloccato correttamente la sessione puoi aprire nuove schede e finestre senza reinserire continuamente la password.

Cosa succede quando chiudo completamente Chrome?

Quando Chrome viene chiuso completamente e successivamente riaperto, Scudo Browser torna a proteggere l'accesso alla nuova sessione e richiede nuovamente la password.

Posso bloccare Chrome senza chiuderlo?

Sì. Puoi utilizzare la funzione “Blocca adesso” per attivare immediatamente la schermata di protezione.

Scudo Browser è gratuito?

Sì. Scudo Browser è gratuito. Il progetto può essere sostenuto facoltativamente tramite una donazione, senza sbloccare funzionalità aggiuntive.

Scudo Browser protegge tutto il computer?

No. Scudo Browser protegge l'accesso alla sessione Chrome tramite l'estensione e non sostituisce le protezioni del sistema operativo.
